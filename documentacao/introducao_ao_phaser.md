Documentando Projeto de iniciação cientifica;

> Para o setup local do phaser.js, preciso de um webserver;

> Para isso vou usar o Vite, que é uma ferramenta que já constrói a base do projeto e vem com um server (é só instalar a seguir);

>comandos:

$ npm create vite@latest

(lembrando que o $ vai simbolizar que estou rodando no terminal do vscode (eu uso o terminal do tipo git, porque tenho ele instalado e iremos usar no desenvolvimento));

> escolhi o framework vue para já criar o projeto automaticamente com o comando do vite;
> escolhi javascript ao invés de typescript;

> em um outro terminal, eu rodei o comando para instalar o phaser js:

$ npm install phaser

** Dúvidas comuns:

> Para parar o live server do vite é só dar um "ctrl + c" no terminal;
> Para rodar de novo é só usar o comando `npm run dev`, tenha certeza que você está dentro do diretório criado;
> Se tiver no terminal do git, pode usar o comando `ls` e depois o `cd {nome_do_diretorio}` para entrar na raiz do projeto.
